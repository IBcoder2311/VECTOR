СТРУКТУРА ТАБЛИЦ:
--users--
id - уник айди
max_id - айди макса
name - имя от макса
img - аватарка. в виде url. дефолт аватарка если не прогрузилось.
desc - описание
skills - навыки. в виде ["","",""]
urls - ссылки на портфолио. в виде ["","",""]
status - user, admin, или organization. 
у всех есть права user(создавать идеи откликаться) 
но не у всех есть права admin(админ панель) и organization(создание мероприятий. у них будет галочка на аве).

--idea--
id - уник айди
owner - владелец идеи. user.id
name - название идеи
short_desc - короткое описание
long_desc - длинное описание
required_roles - необходимые роли
roles - роли которые уже есть. в виде [{"user.id": ..., "role": ...},]
responses - количество откликов
views - количество просмотров
deadline - дедлайн если нет то NULL
region - регион если нет то NULL

--responses--
id - уник айди
id_idea - айди идеи на которую пришел отклик. idea.id
id_user - тот кто оставил отклик. user.id
desc - описание

--events-- (create only user.status=organization)
id - уник айди
owner - user.id
name - название мероприятия
short_desc - короткое описание
long_desc - длинное описание
region - место проведения или регион, если мероприятия не только онлайн. если очно NULL
url - ссылки на сайт для регистрации
url_regulations - ссылки на положение
